Car Black Box — Automotive Event Data Recorder

View Repositories →

Real-time automotive event monitoring and telemetry logging system developed on the PIC18F4580 microcontroller as part of Emertxe's Microcontroller module. Continuously captures critical vehicle metrics and logs timestamped fault/event signatures into non-volatile memory for post-incident diagnostics.

  • Vehicle Parameter Monitoring: Tracks gear shifts, vehicle speed, engine temperature, fuel consumption, and trip distance using timers, interrupts, and GPIO/keypad inputs.
  • I²C Non-Volatile Storage & RTC: Interfaced DS1307 RTC for real-time event timestamping and AT24C02 EEPROM for persistent circular log storage.
  • CAN Bus Communication: Integrated an MCP2551 CAN transceiver to support automotive Controller Area Network data exchange.
  • Secure LCD Interface: Built a password-protected character LCD menu system with UP/DOWN hardware keys for log navigation, clearing memory, and RTC time configuration.
