1. Car Black Box (Automotive Event Data Recorder)

Developed an embedded automotive telemetry and event-logging system on the PIC18F4580 microcontroller as part of Emertxe's Microcontroller module to monitor and record critical vehicle parameters in real time.

  • Vehicle Event Monitoring: Tracks gear shifts, speed, engine temperature, fuel consumption, and trip distance with event signatures and timestamps.
  • Data Storage & Communication: Interfaced AT24C02 EEPROM for non-volatile log storage, DS1307 RTC over I²C for accurate timekeeping, and MCP2551 transceiver for CAN bus communication.
  • User Interface & Security: Designed a character LCD menu interface with password-protected access, UP/DOWN keypad navigation, event log viewing, and RTC time-setting functionality.
